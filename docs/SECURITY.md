# Security model and outstanding gaps

LAN HTTP is plaintext. Use a trusted private network or configure a certificate trusted by the clients using --tls-cert/--tls-key. TLS configuration exists, but actual device deployment remains unverified. Pairing codes require explicit host approval. SHA-256 protects integrity; it does not encrypt or authenticate a network peer.

Opaque credentials are generated by Python secrets. Endpoints enforce participants and recipient access. Cross-origin browser requests are denied. The server uses generated paths instead of user filenames and does not expose arbitrary filesystem paths. WebSocket credentials are sent in the first message rather than URLs.

LAN sessions persist as capability hashes with expiry. Downloads use a short-lived, path-scoped HttpOnly SameSite cookie obtained through an authorized API; credentials never appear in download URLs. Local writes use generated paths, symlink/containment checks, exact chunk lengths, disk reservation, bounded concurrency and metadata/device limits. The host binds a chosen private adapter; it never binds all interfaces by default.

WebRTC files use DTLS encryption, scoped signaling credentials and receiver acceptance. The receiver currently buffers up to 128 MiB. TURN credentials require a valid room capability and expire after ten minutes; actual relay behavior remains unverified.

Send Later uses Web Crypto AES-GCM with random 256-bit keys, a per-key eight-byte nonce prefix and four-byte chunk index. Index zero is reserved for encrypted metadata. AAD binds version, share identifier, chunk index and count. Metadata and each plaintext chunk length must agree with the authenticated manifest. Keys never reach the backend. Do not expose storage buckets publicly.

Release blockers: distributed cloud quota/race safety, storage cleanup retry/orphan reconciliation, full abuse tests, independent review, dependency audits, physical TLS/LAN/relay tests and secure production proxy configuration. Do not expose this development build publicly until those checks are complete.
