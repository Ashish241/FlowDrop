# Privacy

FlowDrop requires no account. The LAN host stores session capability hashes, device display names, file metadata, temporary file chunks and completed payloads. Other participants see authorized device names; transfer listings and downloads are restricted to their own transfers. LAN files are retained for up to 24 hours or until cancellation/deletion; cleanup requires the host process to run.

HTTP LAN traffic is not encrypted. Use a trusted local network or configure trusted TLS. WebRTC uses encrypted DataChannels; STUN and TURN operators may observe network metadata. Signaling retains ephemeral room membership in process memory or Redis. Redis stores capability hashes, approval/connection metadata and expiring hashed rate-limit identities, not file payloads or decryption keys.

Send Later encrypts file chunks and filename/size metadata using browser Web Crypto AES-GCM. The server sees ciphertext sizes, chunk count, expiry and network metadata. Decryption keys stay in the browser and secret URL fragment. Anyone possessing the entire secret link can decrypt. Browser history, extensions, screenshots, clipboard synchronization or an infected device can disclose it.

Revocation prevents future authorized service downloads and requests object deletion. It does not erase already downloaded copies, backups, provider replicas, or storage media remnants. Deletion guarantees depend on the storage provider and operating system. Cleanup checks expired/revoked prefixes including orphan objects every minute while a cloud worker runs; failures are logged without capabilities and retried. Production cleanup monitoring still needs acceptance.

For queue recovery, the browser may persist original plaintext source Files in IndexedDB, scoped to the current capability. Verified sends remove their queue copies; stale entries older than 24 hours are removed when recovery next runs. Closing a tab does not itself erase IndexedDB. Clear browser site data to remove retained source files/history, after preserving any secret links/capabilities you still need. Tab session storage retains Send Later management keys and capabilities until the tab closes. Local transfer analytics/history is not sent to a third-party tracking service. Other people using the same browser profile, extensions and same-origin scripts can access that profile's storage.

Text history stays in page memory and can be cleared. Clipboard access is user initiated; no continuous clipboard monitoring is implemented. Camera access is requested only when the optical receiver is started, and tracks are stopped on Stop/reset/unmount. No analytics or tracking service is included.
